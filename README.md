# Bakery Frontend (Angular)

Arabic RTL bakery management UI.

## Local

```bash
npm install
npm start
```

App: `http://127.0.0.1:4200`  
API (dev): see `src/environments/environment.ts`

## Production env

`src/environments/environment.production.ts` points at the Vercel backend URL.

## Vercel

Static SPA from `dist/frontend/browser` — see `vercel.json`.
